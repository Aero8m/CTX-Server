# 管理端使用与易用性验收

管理端面向老师和班级管理员，以「编辑课表 → 选择教室 → 确认发布 → 查看结果」组织操作。沿用现有 Flask API、原生档案格式、发布历史和设备协议，不需要数据库迁移。

## 常用入口

| 入口 | 用途 |
| --- | --- |
| `/home` | 首次使用任务、课表快捷入口、最近三次发布结果与设备总数 |
| `/profiles` | 新建、导入、编辑、归档和下载课表 |
| `/profiles/new`、`/profiles/:id/edit` | 与客户端一致的分区编辑：基本信息、科目、时间线、课表、提醒与导入备份 |
| `/devices` | 教室列表、连接向导与可选分组；`?pair=1` 直接打开向导 |
| `/publish` | 选择内容、选择教室、预览确认；可携带 `profile`、`display`、`device` 标识 |
| `/releases`、`/releases/:id` | 发布记录与按教室汇总的应用结果 |
| `/display` | 我的配置列表；通过 `/display/new`、`/display/:id/edit` 新建和编辑，支持保存后继续发布 |
| `/guide` | 按任务搜索帮助；`?task=edit`、`pair`、`publish`、`results` 等展开对应说明 |

原有 `/releases?id=…` 链接会跳转到对应结果页。跨页面参数只提供资源或设备标识，进入流程后会重新读取并校验。`/publish?restore=…` 使用历史内容创建一条新发布。

## 日常操作

1. 从工作台新建课表，在「基本信息」填写名称与学期第一天。「科目管理」通过表格与弹窗维护名称、简称和教师；「课表管理」选择周课表与星期后编辑课程。分区通过页面顶部的横向标签切换，沿用网页版配色、字体和卡片样式。
2. 课程可以新增、修改、删除，也可以复制一天到其他星期。新增周课表可复制已有周课表并设置单双周。「时间线管理」提供时间轴画布与右侧编辑面板，支持拖动、边缘调整、缩放、撤销与重做；「课表管理」的「应用到当天」按时间顺序保留科目并更新节次，覆盖前显示数量变化并确认。
3. 网页不再提供临时调课编辑标签，已有临时调课数据在保存和发布时保留，并继续参与日期预览；需要调整时可修改原生档案后重新导入。科目改名会同步课程、来源快照与提醒引用；使用中的科目需先更换引用才能删除。周课表、临时调课与指定科目提醒只能选择已设置科目。旧档案缺少登记的科目可先「补齐缺失科目」，保留已有课程。提醒规则有独立分区。
4. 保存更新草稿；「保存并发布」继续选择教室。我的配置默认保持原样，也可以只发布我的配置。
5. 核对预览中的实际内容和教室名单后确认。分组在预览时展开；预览后内容、修订或成员变化需要重新预览。
6. 结果页每 10 秒刷新。教室本次涉及的全部内容均收到成功回执，才计为「已生效」。设备在线状态、部分成功、失败、阻塞和后续发布替代分别展示。

我的配置与客户端同样按「课程条、外观、桌面倒计时」分区，采用行式设置卡片。课程条的布局预览与组件列表联动，支持拖动或箭头排序、启停、文本提示、课程间距设置与恢复默认。桌面倒计时按基本设置及位置与大小分组。屏幕选择、增强置顶及插件权限继续由教室设备管理。网页修改通过顶部操作栏统一保存与发布，编辑内容直接融入页面，不嵌套桌面窗口外框。

配对向导只有在配对记录出现 `device_id` 后才显示连接成功。ClassTopLand Next 真实桌面客户端尚未接入云同步；目前可以通过向导中的「开发体验」运行模拟设备验证流程。模拟设备不会修改桌面客户端。

保存失败或修订冲突会保留输入，冲突时可以下载备份并载入最新内容。离开课表或我的配置编辑页、切换配置或关闭浏览器时，未保存内容有离开提示。请求默认 30 秒超时，提交结果不确定时只能复用原请求确认结果，避免创建重复发布；确认结果前请保留发布页面。

## 自动化验证

在仓库根目录运行后端回归；在 `frontend` 中运行前端检查：

```powershell
.\.venv\Scripts\python.exe -m pytest backend/tests -q
Set-Location frontend
npm test
npm run build
npm run test:e2e
```

浏览器测试使用隔离测试数据库与 5001／5174 端口。账号和验证码仅由测试进程通过数据库准备，生产 HTTP 接口不增加测试入口。浏览器测试服务关闭限流以隔离用例之间的时间窗口；限流行为仍由后端认证测试验证。

浏览器场景覆盖完整首次使用、390px 编辑与发布、复杂原生档案保留、名称分离、课表及我的配置冲突、未保存离开保护、保存失败、提交响应丢失后的幂等重试、内容与分组变化后的预览失效、仅课表或仅展示及双类型发布、部分生效、离线、阻塞、失败、历史恢复、旧链接、读取失败、配对过期和重新生成。快照输出位于忽略的 `.cache/screenshots/`。

## 配置列表与二级编辑

从“我的配置”列表新建或编辑，按外观、课程条、桌面倒计时、窗口拦截和插件切换。列表支持搜索、分页、下载、归档与恢复。新增两个分区默认不管理设备设置；管理窗口规则时完整替换，插件启用偏好按 ID 合并并在下次启动生效。发布预览可查看覆盖范围。插件专属参数仍由客户端设置。
